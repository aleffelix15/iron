# Modelos 3D

Coloque aqui arquivos `.glb` autorizados (por exemplo `mark-iii.glb`).
O visualizador da Armory (`src/components/ArmorViewer.tsx`) carrega o arquivo
configurado em `src/data/content.ts` (campo `model`) quando ele existir.
Enquanto não houver modelo, o site mostra o reator holográfico procedural.
